# 区域奖学金名额治理服务

面向东盟中文教育项目的奖学金名额治理领域服务，统一管理申请资格、材料版本、
国别与项目配额、定向资金限制和评审回避；评委独立评分后形成**确定性、可解释**的
排序与分配；支持申诉冻结、候补自动递补、并发资金上限守卫，以及审计人员离线重放。

## 治理原则如何落地

| 要求 | 实现 |
| --- | --- |
| 规则修订不可变，修订只能产生新一轮结果 | `rules.RuleBook` 内容寻址（SHA-256），修订顺序发布；轮次开启时冻结规则哈希与每申请人的材料版本；分配结果冻结后不可重跑 |
| 国别 / 项目 / 定向资金三类额度 | `CountryQuota`、`ProgramQuota`（含项目优先级）、`Earmark`（可限国别/项目）+ 通用池；定向池按限制严格度优先消耗 |
| 申请资格与材料版本 | `applications`：必备材料校验、材料每次更新产生新版本号与哈希；轮次引用固定版本，评审期间换材料不影响本轮 |
| 重复报名合并且不泄露隐私 | `identity.IdentityRegistry`：每人生成随机假名 `A-xxxx`，证件/渠道账号仅存进程内登记册，**永不写入事件日志**；合并为单向操作，源申请标记 `superseded`，利益冲突随身份迁移 |
| 评委回避 | 合作关系按自然人身份申报；身份合并后自动覆盖全部渠道申请；存在冲突的评委提交评分直接拒绝 |
| 评委独立评分 | 评分一人一次、提交即锁定、截止后冻结；有效评委数不足的申请不进入排序 |
| 可解释排序 | 排序键：加权总分降序 → 项目优先级升序 → 有效评委数降序 → 申请编号升序；每条录取/落选决策附带资金池、额度占用与落选原因 |
| 放弃/撤销按原规则递补，不能人工插队 | 候补顺序在分配时冻结，永不重排；释放名额后按冻结顺序找第一个国别/项目/定向限制均匹配者自动递补，全过程事件留痕 |
| 申诉只冻结受影响名额 | 申诉仅把该申请加入 `holds`：冻结其名额确认/释放或其候补位置，其他录取与递补照常进行 |
| 并发确认守住资金上限 | 所有写命令在全局锁内「校验 → 追加事件 → 应用」，每次变动后校验国别/项目/资金池三类上限 |
| 审计离线重放 | `audit.replay(日志文件, 轮次)`：校验 SHA-256 哈希链 → 用冻结规则与候选快照重算分配并比对结果哈希 → 输出录取/落选/递补/改判的逐条台账 |
| 重启不改变候补顺序 | 完全事件溯源：重启仅重放日志，候补顺序、冻结、空置名额账本逐位还原；日志含哈希链，篡改即拒绝加载 |

## 模块结构

```
src/scholarship_pool/
├── contracts.py     # 基础契约、规范化 JSON 与哈希工具
├── errors.py        # 治理异常
├── rules.py         # 不可变版本化规则书（配额/定向池/评分维度）
├── identity.py      # 假名身份登记与重复身份合并（隐私最小化）
├── applications.py  # 申请档案、材料版本、资格状态
├── review.py        # 评委登记、利益冲突回避、独立评分会话
├── allocation.py    # 纯函数：评分聚合、确定性排序、额度分配与递补查找
├── journal.py       # 仅追加 + SHA-256 哈希链事件日志
├── service.py       # 主编排：轮次状态机、申诉/改判/并发守卫/事件重放
└── audit.py         # 审计离线重放与裁决台账
```

## 轮次生命周期

```
发布规则修订 → 登记申请/材料 → 申报回避 → 开启轮次(冻结规则+材料版本)
   → 评委独立评分 → 截止评分 → 执行确定性分配(结果冻结)
   → 录取确认 / 申诉(仅冻结该名额) / 放弃·撤销 → 候补自动递补
规则或名额要改 → 发布新修订 → 开启新一轮（历史轮次永远按旧修订重放）
```

## 运行

```bash
# 测试（42 个用例）
python3 -m unittest discover -s tests -v

# 编译检查
python3 -m compileall -q src tests run_cli.py

# 命令行冒烟（完整一轮 + 放弃递补 + 审计重放）
python3 run_cli.py
```

## 离线审计示例

```python
from scholarship_pool import replay

report = replay("journal.jsonl", "ROUND-2026-1")
assert report.chain_ok            # 哈希链完整
assert report.recompute_match     # 用冻结输入重算，与结果哈希一致
report.ledger       # 按序号逐条还原：规则、额度、回避、录取、释放、递补、改判
report.quota_view   # 该国别/项目/定向池额度
report.conflicts_applied  # 每一名被回避评委及其原因
```
