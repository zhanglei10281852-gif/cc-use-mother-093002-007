# 区域奖学金名额治理

面向东盟中文教育项目的奖学金名额治理服务：统一受理申请资格、材料版本、
国别与项目配额、定向资金限制与评审回避，评委独立评分后由确定性引擎
形成可解释的排序与分配方案，全程事件留痕，支持审计离线重放。

## 模块结构（src/scholarship_pool/）

- `rules.py` — 规则集（国别/项目配额、资金池与定向限制、资格材料、评分下限）。
  规则不可变，任何修订只产生新版本号；轮次开启时绑定规则快照。
- `identity.py` — 身份登记：证件号经 HMAC 生成不可逆令牌，重复报名按令牌
  合并，日志与报告中不出现明文个人信息。
- `applications.py` — 申请与材料版本（类别、版本号、摘要、核验状态）。
- `scoring.py` — 评委独立评分（一人一评、不可改）与利益冲突回避
  （按身份令牌生效，换渠道重报也回避）。
- `engine.py` — 确定性分配引擎：不读时钟与随机数，相同输入必得相同输出；
  产出录取/候补/落选决策及完整依据（成绩、回避、额度、阻塞原因）。
- `service.py` — 治理服务门面：轮次生命周期、确认（并发安全、守资金上限）、
  放弃/撤销自动递补、申诉冻结与改判。
- `events.py` — 追加式事件日志，序号连续，重启后据此恢复状态。
- `replay.py` — 离线重放：独立重算分配并与日志比对（防篡改），逐条还原
  录取、落选、递补与改判所使用的规则、额度与回避处理。

## 关键治理规则

- 规则修订只能开启新一轮分配；已封存轮次的结果不可更改。
- 候补递补只由放弃/撤销/改判触发，按本轮原规则扫描，不能人工插队。
- 申诉只冻结受影响的名额，其余录取、确认与递补照常推进。
- 并发确认在锁内校验资金池上限，超额确认一律拒绝。
- 重启后从事件日志恢复，候补顺序与额度保持一致。
